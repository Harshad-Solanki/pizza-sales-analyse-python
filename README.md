## pizza-sales-analyse-python

#🍕 Pizza Sales Analysis using Python

This project is a complete Pizza Sales Analysis performed in Jupyter Notebook using Python libraries for data cleaning, analysis, and visualization.
The objective of this project was to analyze pizza sales data and discover meaningful business insights such as sales trends, peak order hours, best-selling pizza sizes, and customer ordering patterns.

#🔍 Key Analysis Performed
Analyzed total sales and order trends by weekdays and months
Identified peak ordering hours using time-based analysis
Compared pizza size performance by sales and quantity
Performed sales distribution analysis using different visualizations
Extracted insights from date and time columns using Pandas datetime functions
Created interactive and static visualizations for better understanding of business performance
